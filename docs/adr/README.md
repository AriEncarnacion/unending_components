# Architecture decision records

Each file records one decision: what we chose, what we turned down and why, and what follows from it. They're written for people and for coding agents. Read the relevant one before changing something it covers, because the code shows what we did, not what we rejected.

Numbers go up in order and never get reused. An accepted ADR isn't edited. To change a decision, write a new ADR that replaces the old one, and set the old one's status to "Replaced by NNNN".
